## ✨ Sobre o projeto

O **MyRecipeBook** é um projeto criado para praticar o desenvolvimento de uma API REST com **.NET**, simulando um cenário mais próximo do mercado de trabalho.
A proposta vai além de apenas cadastrar receitas: o projeto também busca aplicar **boas práticas de arquitetura, organização de código, versionamento profissional e fundamentos importantes do ecossistema .NET**.

---

## 🚀 Conceitos aplicados

* **ASP.NET Core** para construção da API
* **Entity Framework Core** para persistência de dados
* **Injeção de Dependência** com o container nativo do .NET
* **Princípios SOLID** para um código mais desacoplado e sustentável
* **HTTP Status Codes** aplicados corretamente em APIs REST
* **Boas práticas de Git e Conventional Commits**
* Estrutura preparada para evolução com **testes, CI/CD e deploy**

---

## 🎯 Objetivo

O objetivo do **MyRecipeBook** é servir como um projeto prático de estudo e portfólio, consolidando fundamentos importantes do desenvolvimento back-end com .NET e demonstrando uma construção mais alinhada com o que é exigido no mercado.
